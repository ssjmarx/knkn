## Phaser engine notes (learned from shipped source/types — the standing rule paying off)

- **Typed caches:** loaded files land in per-type caches (`cache.json`, `cache.tilemap`, `cache.image`, …). `tilemapTiledJSON` stores a **wrapper `{ format, data }`** in `cache.tilemap` (TilemapJSONFile.js line 54) — the raw Tiled JSON lives under `.data`. Prefer reading from the `Tilemap` object (`make.tilemap({ key })` → `map.tileWidth` etc.) over peering into caches.
- **Tiled authoring contract:** export maps with tilesets **embedded** (external `.tsx` references don't survive to the browser — the JSON must be self-contained). `addTilesetImage(name-in-map-data, image-key)` — the *name field*, never the `.tsx` filename.
- **Display order:** equal `depth` (default 0) renders by insertion order; higher depth renders on top. `branches.setDepth(1)` is the above-player canopy layer — the general "walks behind" recipe for signs, railings, house fronts.
- **Camera:** `startFollow(target, roundPixels, lerpX, lerpY)`. Lerp 1 = hard-locked — **ruled the accurate GBC feel (2026-09-04)**. Low lerp exposes sub-pixel rounding jitter (two independently rounded floats: `world − scroll`); real GB hardware scrolled whole pixels only, making the artifact impossible on-target — a standing argument for grid-locked movement.
- **`Phaser.Scale.FIT` + `autoRound`** is the adaptive scaling mode (replaces fixed zoom; CRT-friendly).
- **Follower:** `Trail` (dedup push + `atPathDistance` arc-length interpolation) is pure logic — zero Phaser; `Fox` is an arcade body steering toward the arc-length target (`chase`: `min(speed, dist·GAIN)` P-controller, `STOP_RADIUS` 1px, velocity-threshold anim state). No fox↔wall collider — ruled acceptable (the fox threads the player's wake; slight corner clipping on sharp bends).
- **Input stack (Unit 4):** `InputSource` interface (x/y axes + `isDown`/`justPressed`/`endFrame`) with `KeyboardInput` (cursors + `addKey`; `Phaser.Input.Keyboard.JustDown` edges), `TouchInput` (DOM shell buttons; **implicit pointer capture** on touch defeats slide-between-buttons — beaten with window-level listeners + `elementFromPoint` hit-testing + `Map<pointerId, button|null>` where null = a tracked dead-zone finger), `GamepadInput` (`plugin.total` guard — the types claim `pad1` is non-optional, the docs say check; `leftStick` with a manual 0.15 deadzone — `setAxisThreshold` lives on the per-pad `Gamepad` class, not the plugin; rising-edge `justPressed` via `wasDown`), `CompositeInput` (implements the interface it composes; the scene's `create()` is the composition root wiring all three). Touch buttons are DOM in the GBC shell (locked decision #2 realized); landscape = fixed overlay, `pointer-events: none` container + `auto` buttons; `100dvh` for true mobile viewport height.
- **Parallel-scene UI (U5):** `this.scene.launch("DialogueSystem")` + `this.scene.get("DialogueSystem") as DialogueSystem` — locked decision #6's "UI lives in a separate Phaser scene" note, realized for dialogue. GameScene keeps ticking while dialogue shows; the dialogue scene gates its own input with `isShowing`.
- **Containers have no intrinsic size (U5):** `add.container` has zero width/height of its own, so `pointerdown` never fires without an explicit hit area — `button.setInteractive(new Phaser.Geom.Rectangle(-100, -20, 200, 40), Phaser.Geom.Rectangle.Contains)` (hit-area coords are relative to the container's origin).
- **Enter-edge trigger detection (U5):** a `wasInsideTrigger` boolean fires dialogue once per entry into a trigger, not every frame — the same rising-edge idea as `justPressed`, applied to overlap.
- **P4 culled the pass-through chainable setters:** `setImmovable` doesn't exist on `Body | StaticBody` — property assignment (`body!.immovable = true`) is the form, and it typechecks through the union because the property exists on both members (a method must exist on *every* member). Computational setters (`setSize`, `setOffset`) survived.
- **The ambient-namespace trap:** `phaser.d.ts` declares a global `Phaser` namespace, so *type* references resolve anywhere without an import — and a *value* use without an import compiles just as silently, failing only at runtime (dev builds masked it for two units; the prod bundle exposed it). Invariant: Phaser-as-value requires the import; the audit grep is ship ritual.
- **`RectangleToRectangle` counts edge-touching as intersection** (inclusive test); the game's talk predicate is a strict four-inequality positive-overlap test instead.
- **Halting a sprite:** looping animations keep running when the driving code stops calling; `sprite.stop()` then `setFrame(stand)` is the halt idiom (`Player.halt()`).
- **Full-screen overlays:** `setOrigin(0)` + `setScrollFactor(0)` + `setDepth(2000)` = screen-glued and above canopy (1000) and every `body.bottom`; the dialogue box lives in the parallel UI scene, so it renders above the tint — deliberate ("the lamp").
- **Typewriter timing:** the parallel scene's own `update(time, delta)` — accumulate `delta`, spend at fixed ms-per-char; frame-rate independent.

TypeScript & Vitest notes (U6 engine lessons)

    Vitest transforms via esbuild — types are stripped, never checked. A type error in a test passes npm test silently; only tsc catches it. Tests live in the tsconfig include; the runner proves behavior, the compiler proves types.
    Assignability is not exactness (the daynight catch): a 4-field Phase returned where Tint (2 fields) is declared typechecks silently — structural typing proves at least, never only. Exact object shape is expressible only in tests (toEqual), never in types. Sibling of the ambient-namespace trap: compiler silence ≠ runtime truth.
    toBe vs toEqual: identity vs structural contents. Values get toEqual; toBe is reserved for when identity is itself the fact; .not inverts any matcher. Identical literals are identical doubles — exact matchers are safe on transcribed expectations; toBeCloseTo is for arithmetic.
    Purity by injection: tintForHour(hour) → InputSource → Die — the core declares effect contracts, the edges implement them; every random/IO function wears its impurity in its signature. Tests ask worst-case questions with extreme implementations instead of sampling.
    npm scripts: && chains halt on first failure; node_modules/.bin is on the script PATH (bare tsc works inside scripts).

## Engine & test lesson notes (one-line laws — full context in `archive/techContext-lesson-notes.md`)

**Phaser 4:** read the `Tilemap` object, not caches (typed wrappers) · Tiled exports must embed tilesets; `addTilesetImage` takes the name field · depth: higher renders on top, equal = insertion order; canopy at 1000 · camera lerp 1 = hard-locked (ruled GBC feel); `FIT` + autoRound scales (CRT monitor) · **the ambient-namespace trap: a `Phaser.` value use without an import compiles silently and fails at runtime — the audit grep is ship ritual** · containers need explicit hit areas · enter-edge booleans fire once per entry (the overlap sibling of `justPressed`) · P4 culled pass-through setters — property assignment (`body!.immovable = true`) is the form · `RectangleToRectangle` counts edge contact as intersection — the game's talk predicate is strict positive overlap · halt idiom: `sprite.stop()` + `setFrame(stand)` · full-screen overlays: `setOrigin(0)` + `setScrollFactor(0)` + `setDepth(2000)` · typewriter: accumulate `delta` in the scene's own `update`, fixed ms-per-char · parallel-scene UI: `scene.launch` + `scene.get`; the UI scene gates its own input · touch: implicit pointer capture defeated by window-level listeners + `elementFromPoint` + `Map<pointerId, button|null>` · gamepad: guard `plugin.total` (the types lie about `pad1`); manual 0.15 deadzone; rising-edge `justPressed` via `wasDown` · follower: pure `Trail` (arc-length) + `Fox` arcade steering, no fox↔wall collider (ruled).

**TypeScript & Vitest:** Vitest strips types via esbuild — tsc is the only type court · assignability ≠ exactness — a wider object passes a narrower annotation silently; exact shape is test-only (`toEqual`) · `toBe` = identity, `toEqual` = structure; `.not` inverts any matcher · purity by injection (`tintForHour` → `InputSource` → `Die`) — every random/IO function wears its impurity in its signature; worst-case tests use extreme implementations · npm scripts: `&&` halts on first failure; `node_modules/.bin` is on the script PATH.

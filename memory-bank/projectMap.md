## src/compositeinput.ts

The input merger — one InputSource facade standing in for many.
Combines keyboard, touch, and gamepad sources, OR-ing buttons and picking the strongest axis.
GameScene constructs it once and reads all player intent through this single object.

- **class CompositeInput** — Merges several InputSources into one — any source speaking counts.
  - `x()` — The strongest horizontal axis among the sources.
  - `y()` — The strongest vertical axis among the sources.
  - `isDown(action: Button)` — True when any source currently holds the button.
  - `justPressed(action: Button)` — True when any source pressed the button since the last frame.
  - `endFrame()` — Propagates end-of-frame clearing to every source.

## src/config.ts

Global tuning constants — screen size, tile size, speeds, and follower spacing.
Exports plain numbers only; nothing here is computed or ever changes at runtime.
Every module that needs a shared magic number imports from here instead of hardcoding it.


## src/dialogue.ts

The data shapes for conversations — lines, choices, and completion callbacks.
Declares Dialogue and DialogueChoice as plain data, with optional flag effects and per-line callbacks.
dialogues.ts authors content in these shapes; DialogueSystem consumes them at runtime.


## src/dialogues.ts

The game's dialogue content — sample conversations exercising every Dialogue feature.
Exports const tables of Dialogue (plus one string[]) covering plain text, choices, flag reads, and callbacks.
GameScene attaches these to trigger rectangles; DialogueSystem renders whatever they describe.


## src/dialoguesystem.ts

The dialogue overlay scene — renders conversation text and choices above the game.
Steps through Dialogue arrays, resolves conditional text, applies choice flags, and routes input to selection.
Runs as a parallel Phaser scene; GameScene hands it content and polls isShowing/handleInput.

- **class DialogueSystem** — Overlay scene that walks a Dialogue[] and renders its current line.
  - `create()` — Builds the hidden, centered prompt text object.
  - `showDialogue(dialogue: Dialogue[] | string[], flags: Flags)` — Starts a conversation, normalizing plain string lines into Dialogue objects.
  - `showCurrentLine()` — Renders the line at currentIndex, or ends the dialogue when past the last.
  - `showText(text: string)` — Swaps in the prompt text and clears any stale choice buttons.
  - `showChoices(choices: DialogueChoice[])` — Renders clickable choice buttons below the prompt, first one selected.
  - `selectChoice(index: number)` — Highlights the given choice index and records it as selected.
  - `makeChoice(choice: DialogueChoice)` — Applies the choice's flag effect and advances the dialogue.
  - `advance()` — Runs the line's onComplete, moves to the next line, and shows it.
  - `nextLine()` — The A-button continuation path — a thin alias for advance.
  - `endDialogue()` — Hides the prompt and resets all dialogue state.
  - `handleInput(input: InputSource)` — Routes just-presses to choice navigation, or to advancing/skipping lines.

## src/flags.ts

The flag store — a string-keyed record holding all persistent game state.
Creates, reads, writes, checks, and clears entries in one shared mutable record.
Dialogue choices write through DialogueSystem; conditional dialogue text reads from it.

- `createFlags()` — Returns a fresh, empty Flags record.
- `setFlag(flags: Flags, key: string, value: boolean | number | string)` — Writes a value into the store under the given key.
- `getFlag(…)` — Reads a key with a type-safe fallback when it's absent.
- `hasFlag(flags: Flags, key: string)` — Whether the key exists in the store at all.
- `resetFlags(flags: Flags)` — Deletes every entry, leaving the record empty.

## src/fox.ts

The fox companion — a sprite that chases a moving target with eased steering.
Steers toward a trail point each frame, slowing as it nears and stopping inside a small radius.
GameScene drives it from the Trail; it owns no input or pathfinding logic of its own.

- **class Fox** — The follower sprite that steers toward a given target point.
  - `chase(target: Point2 | undefined, speed: number)` — Steers toward the target at the given speed, easing in and stopping when close.

## src/gamepadinput.ts

The gamepad source — maps a physical controller onto the shared Button contract.
Reads the left stick (with deadzone) or D-pad for axes and tracks edges in a wasDown table for justPressed.
Feeds CompositeInput alongside KeyboardInput and TouchInput; no scene touches the pad directly.

- **class GamepadInput** — InputSource backed by the first connected gamepad.
  - `pad()` — The first connected pad, or undefined when none is plugged in.
  - `x()` — Horizontal axis: left stick past the deadzone, else the D-pad.
  - `y()` — Vertical axis: left stick past the deadzone, else the D-pad.
  - `isDown(button: Button)` — D-pad lookup for directions, indexed-button lookup for actions.
  - `justPressed(button: Button)` — Edge detection against the wasDown table, updated as a side effect of the read.
  - `endFrame()` — Nothing to clear — the wasDown table is consumed by justPressed itself.

## src/input.ts

The input abstraction for the whole game — one contract, three sources, one composite.
Defines the Button/Action/Direction unions, KeyboardInput, and the shared guards and axis helper.
Every scene reads player intent through this module; nothing else touches raw keys or DOM.

- **class KeyboardInput** — The keyboard source — one Record<Button, Key> table for the whole pad.
  - `x()` — Held left/right as a horizontal axis.
  - `y()` — Held up/down as a vertical axis.
  - `isDown(button: Button)` — Table lookup: is this button currently held?
  - `justPressed(button: Button)` — Table lookup with JustDown: pressed since last read?
  - `endFrame()` — Nothing to clear — JustDown consumes on read.
- `axis(negative: boolean, positive: boolean)` — Turns two held-direction booleans into a −1/0/1 axis value.
- `isAction(value: unknown)` — Runtime guard: narrows an unknown DOM string to Action.
- `isDirection(value: unknown)` — Runtime guard: narrows an unknown DOM string to Direction.

## src/main.ts

The entry point — boots Phaser with the game's config and scene list.
Builds the 240×240 pixel-art arcade-physics game, registers Boot, Game, and DialogueSystem, and mounts it.
index.html loads this via Vite; every other module hangs off the scenes registered here.


## src/player.ts

The player actor — an arcade sprite driven straight from an InputSource.
Applies axis velocity with diagonal normalization and swaps walk/stand frames based on facing.
GameScene spawns it and calls move() every frame with the composite controls.

- **class Player** — The player sprite plus its facing state and frame math.
  - `move(input: InputSource, speed: number)` — Applies the input axes as velocity and picks the walk or stand animation.
  - `setFacing(vx: number, vy: number)` — Records the dominant direction of motion as the new facing.
  - `standFrame()` — The standing-pose frame index for the current facing.

## src/scenes/bootscene.ts

The boot scene — loads every asset and animation before play begins.
Preloads the sprite sheets and tilemap, registers the pc/fox animations, then hands off to GameScene.
First scene in Phaser's list; nothing renders until its work is done.

- **class BootScene** — Asset-load-and-handoff scene; runs once at startup.
  - `preload()` — Loads the pc/fox sprite sheets, tileset image, and tilemap JSON.
  - `create()` — Registers the walk/idle animations for both sprites and starts GameScene.

## src/scenes/gamescene.ts

The main play scene — map, actors, and the frame loop that wires them together.
Builds the tilemap world, spawns Player and Fox with the Trail between them, and routes input between play and dialogue.
Registered after BootScene; it owns the composite controls and the dialogue trigger check.

- **class GameScene** — The world scene: tilemap, actors, controls, and the update loop.
  - `create()` — Builds the map and collision, spawns the actors, and wires the composite input.
  - `update()` — Per frame: move the player and fox — or forward input while dialogue is showing.
  - `checkDialogueTrigger()` — Starts the trigger's dialogue on the frame the player first enters it.

## src/touchinput.ts

The touch source — on-screen HTML buttons polled through pointer events.
Tracks each finger across down/move/up, mapping it to whichever button it's over and latching just-presses.
Feeds CompositeInput for mobile play; scenes never query the DOM buttons themselves.

- **class TouchInput** — InputSource backed by on-screen buttons under finger tracking.
  - `buttonUnder(event: PointerEvent)` — The <button> element under the pointer, or null when over dead space.
  - `press(button: HTMLButtonElement, down: boolean)` — Sets a button's held/just state and toggles its pressed styling.
  - `x()` — Held left/right as a horizontal axis.
  - `y()` — Held up/down as a vertical axis.
  - `isDown(button: Button)` — Table lookup: is this button currently held?
  - `justPressed(button: Button)` — Whether the button was pressed since the last endFrame.
  - `endFrame()` — Clears every just-pressed latch in preparation for the next frame.

## src/trail.ts

The breadcrumb trail — a capped history of where the player has been.
Records recent positions and answers point-at-distance queries along the walked path.
GameScene feeds it every player step; Fox queries it to follow at a fixed gap.

- **class Trail** — A capacity-capped history of points along the player's walked path.
  - `push(point: Point2)` — Appends a point, dropping the oldest once capacity is exceeded.
  - `last()` — The most recent point, or undefined when nothing has been pushed yet.
  - `atPathDistance(minDistance: number)` — Interpolates the point exactly minDistance back along the walked path.
